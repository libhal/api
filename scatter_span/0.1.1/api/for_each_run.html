for_each_run#

Defined in namespace mem

import scatter_span;

template<typename T, typename U, typename Function>
constexpr void mem::for_each_run(scatter_span<T> p_first, scatter_span<U> p_second, Function &&p_function)#

Walk two scatter spans side by side, one contiguous run at a time.

Calls p_function with the longest pair of spans, one from each scatter span, that starts at the same logical position and is contiguous in both. Each run ends at whichever chunk boundary comes first, so every element of both scatter spans is passed exactly once, in order. Empty chunks are skipped.

While both scatter spans have elements left, the two spans of a run are the same size. Once one of them runs out, its span is empty and the run is the rest of the other’s current chunk. Use this for transfers that move two buffers in lockstep, such as a full duplex bus where one side may be shorter than the other.

Example
std::array<int, 2> a = { 1, 2 };
std::array<int, 3> b = { 3, 4, 5 };
std::array<int, 4> c = { 6, 7, 8, 9 };
std::array<int, 1> d = { 10 };
std::array<int, 1> e = { 11 };

// Runs: ({1, 2}, {6, 7}), ({3, 4}, {8, 9}), ({5}, {10}), ({}, {11})
mem::for_each_run(mem::scatter_span<int>{ a, b },
mem::scatter_span<int>{ c, d, e },
                  [](std::span<int> p_first, std::span<int> p_second) {
// ...
                  });

Template Parameters:

  • T – - element type of the first scatter span

  • U – - element type of the second scatter span

  • Function – - callable as void(std::span<T>, std::span<U>)

Parameters:

  • p_first – - the first scatter span

  • p_second – - the second scatter span

  • p_function – - called once per run, with the first scatter span’s part of the run, then the second’s
